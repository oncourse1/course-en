# موقع بيع كورس "تعلّم وأتقن الإنجليزية بسهولة"

موقع ثابت (Static Site) جاهز — HTML/CSS/JS بسيط، مفيش أي سيرفر أو قاعدة بيانات مطلوبة.

## الصفحات
- `index.html` — الصفحة الرئيسية (Hero + مميزات + معاينة + منهج + سعر + أسئلة شائعة)
- `course.html` — تفاصيل كل مستوى من الـ 12 (تبويبات تفاعلية)
- `about.html` — عن الكتاب/الكورس
- `articles.html` — قائمة المقالات
- `article-vocab.html` / `article-grammar.html` / `article-speaking.html` — 3 مقالات جاهزة
- `contact.html` — نموذج تواصل (يفتح الإيميل حاليًا، راجع "خطوات قبل النشر")

## خطوات لازم تعملها قبل النشر ⚠️

### 1) رابط الدفع (Gumroad) ✅ تم
رابط منتجك على Gumroad متحط في كل أزرار "اشتري":
```
https://courseon.gumroad.com/l/djyfe?wanted=true
```
لاحظ إضافة `?wanted=true` في آخر الرابط — هذي بتخلي الرابط يودّي المستخدم **مباشرة لصفحة الدفع**
بدل ما يوقف على صفحة المنتج الأولى (بما في ذلك زر "I want this" اللي يطلبه Gumroad عادة).

### 2) السعر ✅ تم
السعر الحالي **149.99 ريال سعودي** (مع ذكر ما يعادله ≈ 39.99 $ بخط أصغر تحته في قسم السعر
بالصفحة الرئيسية) متحط في كل الصفحات. لو غيّرت السعر مستقبلًا، ابحث عن "149.99 ريال" و"39.99"
في كل الملفات واستبدلها.

### 3) واتساب ✅ تم (يحتاج تأكيد)
حطينا رابط `https://wa.me/on.course` في كل صفحة. **مهم:** روابط wa.me بشكل رسمي تحتاج
**رقم هاتف دولي** (مثلاً `https://wa.me/9665XXXXXXXX`) عشان تفتح المحادثة صح — يوزرات نصية
زي "on.course" ممكن ما تشتغل مع كل الأجهزة. لو الرابط ما فتح تطبيق واتساب صح عندك،
ابعتلي رقمك بصيغة دولية (966 + الرقم بدون الصفر) وأبدله لك في كل الملفات فورًا.

### 4) نموذج التواصل ✅ تم
نموذج `contact.html` الحين يفتح واتساب مباشرة برسالة معبّاة تلقائيًا (اسم + إيميل + الرسالة)
بدل الإيميل. لو تبي طريقة تانية (نموذج يوصل لإيميلك مباشرة)، استخدم خدمة زي
[FormSubmit](https://formsubmit.co) أو [Formspree](https://formspree.io).

### 5) صورة الغلاف والمعاينات
الصور في مجلد `images/` مأخوذة من نسخة الـ PDF الفعلية. لو غيّرت تصميم الكتاب،
حدّث الصور دي بنفس الأسماء أو غيّر المسارات في الـ HTML.

## إزاي تنشر الموقع (الاستضافة)

أسهل 3 طرق مجانية:

**Netlify (الأسهل):**
1. روح على [netlify.com](https://netlify.com) واعمل حساب مجاني
2. اسحب مجلد الموقع كامل (اللي فيه index.html) على صفحة "Deploys"
3. هيديك رابط فورًا، وتقدر تربط دومين خاص بيك لاحقًا

**GitHub Pages:**
1. ارفع كل الملفات دي في repo على GitHub
2. من Settings → Pages، فعّل النشر من الـ main branch
3. هيديك رابط زي `username.github.io/repo-name`

**Vercel:** نفس فكرة Netlify تقريبًا — اسحب المجلد وهيرفعه.

## الملخص المجاني (Lead Magnet Funnel) 🎁

أضفنا نظام "يد ماجنت" كامل لجمع الإيميلات قبل ما الزائر يشتري:

- **`free.html`** — صفحة هبوط تعرض الملخص المجاني (PDF من 12 صفحة، أهم قاعدة من كل مستوى) مقابل الاسم والإيميل
- **`downloads/english-cheat-sheet.pdf`** — الملف نفسه اللي يتحمّل
- **`thank-you.html`** — صفحة الشكر اللي فيها زر التحميل + عرض الكورس الكامل (upsell)

### كيف يشتغل حاليًا
النموذج في `free.html` يستخدم خدمة **[FormSubmit.co](https://formsubmit.co)** المجانية —
ترسل بيانات كل شخص يسجّل مباشرة لإيميلك، بدون أي سيرفر أو حساب معقّد.

**خطوة لازمة قبل النشر:**
1. افتح `free.html` ودوّر على `https://formsubmit.co/YOUR-EMAIL@example.com`
2. استبدلها بإيميلك الحقيقي
3. أول شخص يسجّل (أو جرّب إنت بنفسك)، بيوصلك إيميل من FormSubmit لازم تفتحه وتضغط
   "Activate" — من بعدها الفورم يشتغل تلقائي ويودّي كل تسجيل بعده لإيميلك

### لو تبي تنتقل لخدمة إيميل ماركتنج لاحقًا (Mailchimp / ConvertKit)
لما يصير عندك حساب، بس استبدل الـ `<form>` بالكامل في `free.html` بكود الفورم اللي
تعطيك إياه الخدمة (كل وحدة عندها "Embed Form" أو "Landing Page" جاهز تنسخه). باقي الصفحة
(التصميم، النص، الروابط) تفضل زي ما هي.

### الترويج للملخص المجاني
ضفنا رابط "ملخص مجاني" في قائمة التنقل بكل صفحات الموقع. لو تبي تخليه أبرز، تقدر تضيف:
- بانر علوي فوق الهيدر في `index.html` يوجّه لـ `free.html`
- قسم مخصص في الصفحة الرئيسية قبل قسم الأسعار
- الموقع بيستخدم خطوط Google Fonts (Amiri, Cairo, Aref Ruqaa) عبر رابط CDN — محتاج اتصال إنترنت عادي، مفيش تثبيت مطلوب.
- التصميم متجاوب (Responsive) — بيشتغل كويس على الموبايل والتابلت والكمبيوتر.
- زرار "القائمة" في الموبايل، والأسئلة الشائعة القابلة للطي، وتبويبات المنهج — كلها شغالة بجافاسكريبت بسيط في `js/main.js` بدون أي مكتبات خارجية.
